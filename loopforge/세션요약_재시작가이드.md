## ⏳ 재시작 시 바로 이어할 작업 (순서대로)

### 🔴 1순위 — ngrok + n8n 웹훅 연결

#### Step 1. ngrok 실행
```powershell
cd "D:\1인기업\LoopForge AI"
ngrok http 5678
# → https://xxxx.ngrok-free.app URL 복사
```

#### Step 2. n8n 워크플로우 생성
1. http://localhost:5678 접속
2. New Workflow → 이름: `LoopForge - 문의 수신`
3. Webhook 노드 추가:
   - HTTP Method: POST
   - Path: `loopforge-contact`
4. Google Sheets 노드 연결:
   - Operation: Append Row
   - 컬럼: business_name, business_type, contact, review_sample, submitted_at
5. Activate 토글 ON

#### Step 3. Worker Secret 업데이트
```powershell
$env:CLOUDFLARE_API_TOKEN = "Cloudflare API Token 입력"
# (보안상 여기에 기재 안 함 — 이전 세션 요약 파일 참고)

wrangler secret put N8N_WEBHOOK_URL --name loopforge-contact-proxy
# 입력값: https://xxxx.ngrok-free.app/webhook/loopforge-contact

wrangler secret put ALLOWED_ORIGINS --name loopforge-contact-proxy
# 입력값: https://loopforge-2v1.pages.dev

wrangler secret list --name loopforge-contact-proxy
```

#### Step 4. 전체 흐름 테스트
```powershell
# 폼 제출 테스트 (PowerShell)
$body = @{
    business_name = "테스트 카페"
    business_type = "카페"
    contact       = "010-1234-5678"
    review_sample = "테스트 리뷰입니다"
    privacy_agree = $true
    turnstile_token = "XXXX"  # 실제 테스트는 브라우저에서
    submitted_at  = (Get-Date -Format "o")
} | ConvertTo-Json

Invoke-RestMethod `
    -Uri "https://loopforge-contact-proxy.wnsrua01.workers.dev" `
    -Method POST `
    -ContentType "application/json" `
    -Body $body
```
